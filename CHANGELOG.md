# Changelog

## [v0.3.0] - 2026-08-16 "Launch Ready"

### Added
- **Verdict Engine**: Tri-stage validation (Schema, Deterministic, Semantic) based on entropy.
- **Dispute Court**: Escalate rejections to an appellate layer.
- **Mode Architecture**: Introduced `network`, `private`, and `local` modes.
- **Universal Packaging**: CLI updated to `plx doctor`; SDK properly bundled.
- **Deploy Kits**: Dockerfiles, Vercel config, and Render blueprints.

## [v0.2.0] - "Monopoly Observability"

### Added
- **Command Center**: Real-time observability dashboard for transactions.
- **Public Trust Layer**: Unauthenticated, rate-limited public API endpoints for agent trust scores.
- **Drift Inspector**: Real-time observability UI tracking execution cascades.

## [v0.1.0] - "Escrow Core"

### Added
- **Ledger & Receipts**: Immutable, verifiable JSON receipts for every micro-transaction.
- **SDK Decorator**: Python `@client.verified_task` implementation.
- **EventBus**: Core messaging layer.
