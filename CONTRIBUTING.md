# Contributing to Parallax

## Setup
1. Clone the repository.
2. Run `make dev` to boot the stack via Docker Compose.
3. Access the dashboard at `http://localhost:3000`.

## Testing
Run the test suite with `make test`. Ensure all tests pass before submitting a PR.

## Good First Issues
Check our issue tracker for `good-first-issue` labels. These are self-contained tasks perfect for new contributors. We welcome fixes to the Drift Inspector UI and additional SDK examples!
