# Journey: Non-coder Operator

The Studio flow allows operators to visually compose tasks.

1. **Schema Create**: The operator selects or builds a schema (e.g. `PriceCheck`) visually.
2. **Task Compose**: The operator fills in the task parameters (buyer, seller, amount).
3. **Verdict**: The operator clicks "Run" and observes the real-time verdict via the API equivalents.

This flow is verified via `journey_operator.py`.
